# Bank Simulator

Sistema de administración bancaria desarrollado en Java aplicando
principios de programación orientada a objetos.

## Funcionalidades

- Gestión de usuarios
- Gestión de cuentas
- Transacciones bancarias
- Depósitos y retiros
- Administración de información

## Tecnologías

- Java
- Programación Orientada a Objetos
